KB0090: Virtual Desktop Connection Problems

Applies to: the virtual desktop client used by contractors and remote call-center staff.

Session Connects Then Disconnects

If a virtual desktop session opens and then disconnects within a minute, the usual cause is an unstable home connection or a power-saving setting on the network adapter. Plug in a network cable if possible and disable adapter power saving.

Black Screen After Login

Wait two minutes for the profile to load. If the screen stays black, sign out from the client menu and sign in again. Do not close the client window while a session is loading.

When to Open a Ticket

Open a ticket if disconnects continue after the steps above, and include the session ID shown in the client's About menu.
