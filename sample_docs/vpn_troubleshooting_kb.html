KB0042: VPN Connection Troubleshooting

Applies to: GlobalProtect client, all supported OS versions.

Symptom

User reports VPN client fails to connect, hangs at "Connecting..." or returns error code 3 ("Unable to connect to the service").

Common Root Causes

  • Expired or revoked client certificate (most common - roughly 40% of tickets)
  • Local firewall or endpoint security software blocking the VPN adapter
  • Stale DNS cache pointing to a decommissioned gateway
  • Gateway-side capacity saturation during peak hours (8-9am local time)

Triage Steps

  1. Check the identity provider for certificate expiration on the user's account.
  2. Have the user run the built-in diagnostic tool and capture the log bundle.
  3. If certificate is valid, check gateway health dashboard for regional saturation.
  4. If none of the above resolve it within 15 minutes, escalate to Network Engineering with the log bundle attached.

Self-Service Fix

For expired certificates, users can regenerate their own client certificate from the self-service identity portal without opening a ticket. This is the single highest-impact self-service deflection opportunity in the VPN category.
