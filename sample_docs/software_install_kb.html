KB0118: Requesting and Installing Software

Applies to: company-managed Windows and macOS laptops.

Self-Service Software Catalog

Most approved applications can be installed without a ticket from the Company Portal app (Windows) or Self Service app (macOS). Search for the application, click Install, and keep the laptop on and connected until the install finishes. Catalog installs usually complete within 10 minutes.

Software Not in the Catalog

  1. Submit a Software Request in the Service Portal with the product name, vendor, version, and business justification.
  2. The request routes to your manager for approval.
  3. Security reviews any new vendor, including data handling and licensing. Allow 5 business days for review.
  4. Once approved, IT packages the application and adds it to the catalog, then notifies you to install it yourself.

Common Install Problems

  • Install stuck at "Pending": the laptop has not checked in with device management. Restart, connect to the corporate network, and wait 15 minutes.
  • "Not available for your device": the application is limited to certain departments or operating systems. Submit a Software Request.
  • Install fails with an error: retry once. If it fails again, open a ticket and include the exact message shown and a screenshot.

Policy Reminder

Users do not have local administrator rights, and installing unapproved software with workarounds violates the Acceptable Use Policy. Browser extensions follow the same approval process as desktop applications.
